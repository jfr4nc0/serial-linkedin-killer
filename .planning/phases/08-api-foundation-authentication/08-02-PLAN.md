**Required methods:**

1. `get_authorization_url(state: str | None = None) -> str` -- Build LinkedIn OAuth2 authorization URL with client_id, redirect_uri, scopes from config, response_type=code, and optional state parameter for CSRF protection. Return the full URL string. Do NOT use authlib session for this -- just build the URL with urllib.parse.

2. `exchange_code_for_token(code: str) -> dict` -- POST to TOKEN_URL with grant_type=authorization_code, code, redirect_uri, client_id, client_secret. Use httpx to make the request. Parse response for access_token and expires_in. Calculate expires_at = time.time() + expires_in. Store token in DB via `_save_token(organization_urn, access_token, expires_at)`. Return dict with access_token and expires_at. Raise ValueError on error response.

3. `_save_token(organization_urn: str, access_token: str, expires_at: float)` -- Upsert LinkedInOAuthToken row using session.merge() (follow AgentDB pattern).

4. `_load_token(organization_urn: str) -> LinkedInOAuthToken | None` -- Query LinkedInOAuthToken by PK. Return None if not found.

5. `get_valid_token(organization_urn: str | None = None) -> str` -- Load token from DB (use config.linkedin_api.organization_urn if not provided). Check expiration: if expired, raise `TokenExpiredError`. If within `config.campaign.token_expiry_warning_days` of expiry, log WARNING with days remaining and expiry date. Return access_token string.

6. `check_token_health(organization_urn: str | None = None) -> dict` -- Return dict with keys: valid (bool), expires_at (float or None), days_remaining (float or None), needs_reauth (bool), warning (str or None). Used by health checks and alerting.

7. `_make_api_request(method: str, path: str, organization_urn: str | None = None, **kwargs) -> httpx.Response` -- Core request method. Gets valid token via `get_valid_token()`. Sets headers:
   - `Authorization: Bearer {token}`
   - `LinkedIn-Version: {API_VERSION}`
   - `X-Restli-Protocol-Version: 2.0.0`
   - `Content-Type: application/json`
   Makes request via httpx. On 401 response: raise `TokenExpiredError("LinkedIn API returned 401. Token expired or revoked. Re-authorize at: {authorize_url}")`. On 429: raise `RateLimitError` with retry-after header value. Return response for other status codes.

8. `create_post(text: str, organization_urn: str | None = None, visibility: str = "PUBLIC") -> dict` -- POST to `/rest/posts` with body:
   ```json
   {
     "author": "urn:li:organization:{org_id}",
     "commentary": "{text}",
     "visibility": "PUBLIC",
     "distribution": {
       "feedDistribution": "MAIN_FEED",
       "targetEntities": [],
       "thirdPartyDistributionChannels": []
     },
     "lifecycleState": "PUBLISHED",
     "isReshareDisabledByAuthor": false
   }
   ```
   Use `_make_api_request`. Return parsed JSON response (includes post URN in `id` field or `x-restli-id` header).

**Custom exceptions** (define at module top):

```python
class LinkedInAPIError(Exception):
    """Base exception for LinkedIn API errors."""
    pass

class TokenExpiredError(LinkedInAPIError):
    """Raised when OAuth2 token is expired or revoked."""
    def __init__(self, message: str, reauth_url: str | None = None):
        super().__init__(message)
        self.reauth_url = reauth_url

class RateLimitError(LinkedInAPIError):
    """Raised when LinkedIn API rate limit is hit."""
    def __init__(self, message: str, retry_after: int | None = None):
        super().__init__(message)
        self.retry_after = retry_after
```

**Important design notes:**
- Use httpx.Client (sync), NOT async. The existing codebase uses sync patterns with thread pool for async (see OutreachService).
- Do NOT use authlib's OAuth2Session -- it adds complexity for a simple authorization code flow. Just use httpx for the token exchange POST. authlib is in deps for potential future use (token refresh if LinkedIn ever enables it) and for its utilities, but KISS for now.
- Do NOT import or reference anything from `src/linkedin_mcp/` -- complete separation from RPA auth.
- Follow the config loading pattern from `llm_client.py` -- use `load_config()` to get credentials.
- Follow the DB session pattern from `agent_db.py` -- create session factory from engine, use `with self._session_factory() as session:` context manager.
- Log at INFO level for token operations, WARNING for expiry warnings, ERROR for auth failures. Use loguru.

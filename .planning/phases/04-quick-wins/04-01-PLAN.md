   - Create a class `BoundedLRUCache` that wraps `OrderedDict`:
     ```python
     class BoundedLRUCache:
         """Dict-like LRU cache with a max size. Evicts oldest on overflow."""
         def __init__(self, max_size: int = 10000):
             self._data = OrderedDict()
             self._max_size = max_size

         def __contains__(self, key):
             return key in self._data

         def __getitem__(self, key):
             self._data.move_to_end(key)
             return self._data[key]

         def get(self, key, default=None):
             if key in self._data:
                 self._data.move_to_end(key)
                 return self._data[key]
             return default

         def update(self, mapping):
             for k, v in mapping.items():
                 self._data[k] = v
                 self._data.move_to_end(k)
             while len(self._data) > self._max_size:
                 self._data.popitem(last=False)

         def __len__(self):
             return len(self._data)
     ```
   - Initialize: `_title_cache = BoundedLRUCache(load_config().llm.title_cache_max_size)`
   - The existing usage patterns (`t in _title_cache`, `_title_cache[t]`, `_title_cache.update(all_validated)`) will work unchanged with the BoundedLRUCache interface.
   - Add a log line in `update()` or after `_title_cache.update(all_validated)` on line 233 that logs when eviction occurs:

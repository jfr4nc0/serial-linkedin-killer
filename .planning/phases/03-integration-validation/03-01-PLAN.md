  <name>Task 1: Pre-bind Langfuse callbacks in get_llm_client()</name>
  <files>src/core/providers/llm_client.py</files>
  <action>
Modify `get_llm_client()` in `src/core/providers/llm_client.py` to pre-bind Langfuse callbacks on the LLM client before caching and returning it. This ensures that any consumer calling `llm.invoke(...)` (including `role_clustering.py` which does NOT pass callbacks explicitly) will automatically have Langfuse tracing active.

Implementation steps:

1. Add import for `get_langfuse_callback` from `src.core.observability.langfuse_config`.

2. After creating the client (either ChatOpenAI or ChatGoogleGenerativeAI), check if Langfuse is configured by calling `get_langfuse_callback()`.

3. If a callback handler is returned (not None), use LangChain's `.with_config({"callbacks": [handler]})` method to create a new runnable with callbacks pre-bound. This returns a `RunnableBinding` that wraps the original client but automatically passes callbacks on every `.invoke()` call.

4. Add provider metadata to the callback handler before binding: set `handler.metadata = {"provider": provider}` so traces identify which LLM provider was used. This satisfies Success Criterion 3 (provider identification in trace metadata).

5. Cache the BOUND client (with callbacks), not the raw client. This way every call through the cached client includes tracing.

6. IMPORTANT: `get_langfuse_callback()` returns None when Langfuse credentials are missing. In that case, cache and return the raw client unchanged. This preserves backward compatibility for users without Langfuse configured.

7. The return type remains `BaseChatModel`. The `RunnableBinding` returned by `.with_config()` is compatible with `BaseChatModel` interface — it has `.invoke()`, `.batch()`, etc.

8. Do NOT modify `role_clustering.py` — this is the INT-01 requirement. The whole point is that tracing works WITHOUT changes to consumers.

Code structure after modification:
```python
from src.core.observability.langfuse_config import get_langfuse_callback

def get_llm_client() -> BaseChatModel:
    # ... existing provider resolution and cache check ...

    # ... existing client creation (ChatOpenAI or ChatGoogleGenerativeAI) ...

    # Pre-bind Langfuse callbacks for automatic tracing
    langfuse_handler = get_langfuse_callback()
    if langfuse_handler is not None:
        langfuse_handler.metadata = langfuse_handler.metadata or {}
        langfuse_handler.metadata["provider"] = provider
        client = client.with_config({"callbacks": [langfuse_handler]})

    # Cache and return
    _llm_cache[provider] = client
    return client
```

AVOID:
- Do NOT call `configure_langfuse()` directly — use the `get_langfuse_callback()` wrapper which already handles that.
- Do NOT add callbacks parameter to the function signature — this would require consumer changes.
- Do NOT import langfuse directly — go through the existing `langfuse_config.py` abstraction.

<objective>
Eliminate O(n^2) list copying in LangGraph pagination loops for both EmployeeSearchGraph and JobSearchGraph.

Purpose: Each pagination iteration currently creates `state["list"] + new_items`, which allocates a brand new list containing all previous items plus new ones. Over 20 iterations (employees) or 10 pages (jobs), this creates O(n^2) total memory allocations. Using LangGraph's built-in `Annotated` reducer pattern, nodes return only the NEW items and LangGraph appends them automatically.

Output: Both graph state types use `Annotated[list, operator.add]` reducers; all graph nodes return only delta dicts.
</objective>

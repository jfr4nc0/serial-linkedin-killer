  <name>Task 1: Add langchain-google-genai v2.1.12 via Poetry</name>
  <files>pyproject.toml, poetry.lock</files>
  <action>
Run `poetry add "langchain-google-genai@~2.1.12"` to add the dependency with a tilde constraint (~2.1.12), which allows patch updates within 2.1.x but prevents minor version bumps that could pull in incompatible langchain-core requirements.

**CRITICAL version constraint:** Use v2.1.12 specifically (NOT v4.x). The research phase confirmed via `pip install --dry-run` that:
- v2.1.12 requires `langchain-core>=0.3.75` — our installed 0.3.83 satisfies this
- v4.x requires `langchain-core>=1.2.5` — would force langchain-core 0.3.83 -> 1.2.11, breaking all existing LangChain packages

If `poetry add` fails with dependency resolution errors:
1. Check the error message for conflicting langchain-core version constraints
2. Try `poetry add "langchain-google-genai==2.1.12"` with exact pin as fallback
3. Do NOT allow langchain-core to upgrade to 1.x — this is a non-negotiable constraint

After `poetry add` succeeds:
1. Verify with `poetry show langchain-google-genai` that version is 2.1.x
2. Verify with `poetry show langchain-core` that version remains 0.3.x
3. Verify with `poetry show langchain-openai` that version remains 0.3.x (no collateral upgrades)
  </action>

**Endpoints:**

1. `POST /api/campaigns` (response_model=CampaignDetailResponse, status_code=201):
   - Accepts CampaignCreateRequest body
   - If sentiments not provided, use config.campaign.default_sentiments
   - If organization_urn not provided, use config.linkedin_api.organization_urn
   - Raise 400 if organization_urn is empty after defaults
   - Calls service.create_campaign(), then service.get_campaign() to return full detail
   - Returns 201

2. `GET /api/campaigns` (response_model=CampaignListResponse):
   - Optional query param: organization_urn (str, default None)
   - Calls service.list_campaigns(organization_urn)
   - Returns CampaignListResponse with campaigns list and total count

3. `GET /api/campaigns/{campaign_id}` (response_model=CampaignDetailResponse):
   - Calls service.get_campaign(campaign_id)
   - Returns 404 with detail "Campaign not found" if None

4. `PATCH /api/campaigns/{campaign_id}` (response_model=CampaignDetailResponse):
   - Accepts CampaignUpdateRequest body
   - Calls service.update_campaign()
   - Returns 404 if campaign not found (service returns None)
   - Returns 400 with detail from ValueError message if campaign is not in draft status
   - On success, calls service.get_campaign() to return full detail with variants

5. `DELETE /api/campaigns/{campaign_id}` (response_model=CampaignDeleteResponse):
   - Calls service.delete_campaign()
   - Returns 404 if not found

6. `POST /api/campaigns/{campaign_id}/status` (response_model=CampaignDetailResponse):
   - Accepts CampaignStatusTransition body
   - Calls service.transition_status()
   - Returns 404 if campaign not found (ValueError with "not found")
   - Returns 400 if invalid transition (ValueError with transition message)
   - On success, calls service.get_campaign() to return full detail

**Error handling pattern** (consistent with outreach_controller.py):
- ValueError -> HTTPException(400, detail=str(e))
- None returns -> HTTPException(404, detail="Campaign not found")
- Generic Exception -> HTTPException(500, detail=str(e))

Import schemas from campaign_schemas.py, service from campaign_service.py.

<task type="auto">
  <name>Task 2: Create CampaignService with CRUD and status lifecycle</name>
  <files>src/core/api/services/campaign_service.py</files>
  <action>
Create CampaignService class following the AgentDB pattern (takes Engine or URL in __init__, creates _session_factory). Do NOT subclass AgentDB -- keep it a standalone service.

**Constructor:**
- `__init__(self, engine_or_url)`: Accept Engine or str, create session factory via create_session_factory. Store config via load_config().

**Status machine -- define as class-level dict:**
```python
VALID_TRANSITIONS = {
    "draft": ["scheduled", "active", "failed"],
    "scheduled": ["active", "paused", "failed"],
    "active": ["paused", "completed", "failed"],
    "paused": ["active", "completed", "failed"],
    "completed": [],  # terminal
    "failed": ["draft"],  # allow retry from failed
}
```

**CRUD methods:**

1. `create_campaign(self, base_message: str, sentiments: List[str], organization_urn: str, scheduled_at: Optional[float] = None) -> dict`:
   - Create Campaign row with status="draft"
   - Create CampaignVariant rows (one per sentiment) with empty content="" and is_selected=1. Content will be filled by Phase 10 (Content Generation). Sentiment name is stored now for generation later.
   - Return campaign dict with id, status, variant_count, created_at

2. `list_campaigns(self, organization_urn: Optional[str] = None) -> List[dict]`:
   - Query Campaign table, optionally filtered by organization_urn
   - For each campaign, count variants via subquery (filter by campaign_id on CampaignVariant)
   - For each campaign, get latest metrics aggregation: sum the most recent CampaignMetric per variant_id (subquery: for each variant_id, get the row with max polled_at, then sum across variants)
   - Return list of dicts matching CampaignListItem shape
   - Truncate base_message to 100 chars with "..." suffix if longer
   - Order by created_at DESC

3. `get_campaign(self, campaign_id: str) -> Optional[dict]`:
   - Load Campaign by id
   - Load all CampaignVariant rows for this campaign_id (ordered by created_at)
   - Load latest metrics aggregation (same as list but for single campaign)
   - Return dict matching CampaignDetailResponse shape, or None if not found

4. `update_campaign(self, campaign_id: str, base_message: Optional[str] = None, scheduled_at: Optional[float] = None) -> Optional[dict]`:
   - Load campaign, return None if not found
   - Raise ValueError if campaign.status != "draft" (only draft campaigns can be edited)
   - Update provided fields, set updated_at = time.time()
   - Return updated campaign dict (same shape as get_campaign)

5. `delete_campaign(self, campaign_id: str) -> Optional[dict]`:
   - Soft delete: set status to "deleted", set updated_at = time.time()
   - Do NOT delete CampaignVariant, CampaignMetric, or CampaignLead rows (preserve history)
   - Return dict with id, status="deleted", deleted_at
   - Return None if campaign not found
   - Add "deleted" to the set of statuses but NOT to VALID_TRANSITIONS (can't transition out of deleted)

6. `transition_status(self, campaign_id: str, target_status: str) -> dict`:
   - Load campaign, raise ValueError if not found
   - Validate transition: check VALID_TRANSITIONS[current_status] contains target_status
   - Raise ValueError with descriptive message if invalid (e.g. "Cannot transition from 'completed' to 'draft'. Valid transitions from 'completed': none (terminal state)")
   - Update status, set updated_at = time.time()
   - Return campaign dict with updated status

Use `with self._session_factory() as session:` context manager pattern (consistent with agent_db.py). All query methods use session.query() ORM-style (consistent with existing code).
